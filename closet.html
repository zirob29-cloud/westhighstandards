What's inside

We organize items so students can find what they need quickly and privately. The room is set up like a warm boutique rather than a storage closet.

Inventory categories

  • Everyday Wear: T-shirts, long-sleeves, jeans, khakis, sweatpants, hoodies, skirts.
  • Dress Code / Uniform Essentials: Solid polos, dark slacks/shorts, plain belts.
  • Outerwear & Seasonal: Winter coats, rain jackets, snow boots, gloves, scarves, beanies.
  • Footwear: Athletic sneakers, rain boots, slip-on shoes across youth sizes.
  • New-in-Package Basics: Underwear, socks, sports bras (new only).
  • Special Occasion / Spirit Wear: School tees, spirit gear, formalwear for events.

Room setup

  • Display racks sorted by size and type
  • Full-length mirrors and a private fitting area
  • Clear labeling system with size dividers
  • Intake and sorting area for donations

Acceptance & hygiene

We accept gently used, clean clothing. New underwear and socks only. Donated items are inspected and laundered when necessary.
